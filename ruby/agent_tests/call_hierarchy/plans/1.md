# Plan: Fix Ruby Call Hierarchy

## Status: IMPLEMENTED — 23/25 tests pass

### What was wrong

Two issues in `RubyHandlers.kt`:

1. **Callees returned empty** — used `PsiTreeUtil.findChildrenOfType(rMethod, RCall.class)` but Ruby
   PSI represents method calls as `RIdentifierImpl` nodes (extending
   `RubyStubBasedPsiElementBaseWithReference`), **not** `RCall` nodes. `RIdentifierImpl` has
   `getReference()` but does **not** implement the `PsiReference` interface, so `is PsiReference`
   also failed.

   **Fix**: use reflection to call `getReference()` on every PsiElement child of the method body,
   then resolve the returned `PsiReference`.

2. **Scope leak** — `ReferencesSearch` found references in `.md` test files because Ruby language
   injection makes injected Ruby code blocks have language="ruby". Checking `language.id != "ruby"`
   doesn't filter them.

   **Fix**: check file extension via `containingFile?.virtualFile?.name` — only `.rb` and `.rake`
   files are valid sources.

### Implementation (RubyHandlers.kt)

#### findCalleesRecursive() — replace RCall search with reflective getReference()

```kotlin
val callRefs = mutableListOf<PsiElement>()
val allElements = PsiTreeUtil.collectElementsOfType(rMethod, PsiElement::class.java)
for (child in allElements) {
    if (child === rMethod) continue
    if (callRefs.size >= MAX_RESULTS_PER_LEVEL * 2) break
    try {
        val ref = child::class.java.getMethod("getReference").invoke(child) as? PsiReference
        if (ref != null) callRefs.add(child)
    } catch (_: NoSuchMethodException) {}
}
```

`resolveCallTarget()` needs no changes — its Strategy 2 (`(callExpr as? PsiReference)?.resolve()`)
works for the returned PsiReference.

#### findCallersRecursive() — add file extension filter

```kotlin
val refFile = refElement.containingFile?.virtualFile
if (refFile != null && !refFile.name.endsWith(".rb") && !refFile.name.endsWith(".rake") && !refFile.extension.isNullOrEmpty()) continue
```

### Remaining known issues

1. **`testSymbolBasedLookup`** — `RubySymbolReferenceHandler.resolveSymbol()` is a stub.
   Needs `RubyMethodNameIndex` or `RubyClassModuleNameIndex` lookups with `RClass.findMethodByName()`.
   Separate task.

2. **`testPositionOutsideMethod`** — positions on `end` keywords or blank lines fail.
   This is expected: `findElementAt()` returns a leaf not inside any RMethod. The test should
   use positions on method names (e.g., `def target` at line 9, column 5) or method bodies.

3. **Some test .md files have wrong line numbers** — e.g. `callers_depth.rb` target is at L9C5,
   not L7C5 as stated in the test plan file. The line numbers were written assuming a different
   file layout (no blank lines between methods).
